# Student Grade Management System

## Project Overview
The Student Grade Management System is a Python-based application designed to manage student records efficiently. It allows users to add, view, update, delete, and search student details while automatically calculating grades and pass/fail status based on marks.

## Features
- Add new student records
- View all student records
- Search students by Roll Number
- Update student information
- Delete student records
- Automatic Grade Calculation (A, B, C, D, F)
- Pass/Fail Status
- Menu-driven interface

## Technologies Used
- Python
- VS Code

## Concepts Used
- Functions
- Dictionary
- Conditional Statements
- Loops
- User Input
- CRUD Operations

## How to Run
1. Clone this repository.
2. Open the project in VS Code.
3. Run the Python file.
4. Follow the menu displayed on the screen.

## Project Output
The application manages student records and displays grades with pass/fail status based on marks.
